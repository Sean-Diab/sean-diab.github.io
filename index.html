Projects

Reviser

Solo research project · Dec 2025–Apr 2026

Revision-capable language modeling via autoregressive cursor actions over a mutable token canvas ( Insert/Move/Stop ).

  • Built model, data pipeline, training loop, inference tooling, and evaluation stack in PyTorch.
  • Ran 3k-sample pairwise LLM-judge arenas; achieved 61.3% (100M) and 54.4% (300M) 1v1 win rate vs matched AR baselines, and 85.9%/78.3% vs SEDD/MDLM, on response quality.
  • Released code and paper; filed U.S. Provisional Patent Application.

FaceOff

Solo project · Jan 2026–Jul 2026

A real-time social platform for Clash Royale, built and operated end-to-end: live screen-share streaming with a TikTok-style watch experience, automatic opponent detection that connects two matched players in live voice chat, per-match replay clips, and a public short-video community feed.

  • Computer-vision matchmaking: masked template matching + OCR over ReplayKit screen capture recognizes when two users are in the same match and auto-connects them in a LiveKit voice room; cut cross-device detection skew from 14 s to sub-second.
  • Real-time media stack: native-resolution VP9 screen share over LiveKit/WebRTC, server-side ffmpeg recording with wall-clock CFR pacing for drift-free audio/video, and automatic per-match replay clipping anchored to Supercell API battle timestamps.
  • Production backend: FastAPI + PostgreSQL (asyncpg/Alembic), APNs/VoIP push, Apple/Google sign-in, moderation and rate limiting; deployed with systemd, Cloudflare Tunnel, and a dedicated LiveKit SFU; tested with pytest, XCUITest, and Maestro flows.
  • SwiftUI iOS app: broadcasting, live watching with chat, DMs and CallKit voice calls, multi-account Clash Royale profiles, and a battle log with auto-attached replay clips.
